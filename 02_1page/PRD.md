# PRD: 1페이지 개인 홈페이지

> 이 문서는 `CLAUDE.md`의 지침을 바탕으로 작성했습니다. `[ ]`로 표시한 항목은 소유자에게 받아야 하는 정보이며, 받기 전까지 임의로 채우지 않습니다.

## 1. 개요

1990년생 소유자를 소개하고 포트폴리오와 개발 능력을 알리는 한 페이지짜리 개인 홈페이지를 만든다. 방문자는 스크롤 한 번으로 소유자가 누구이고, 무엇을 만들 수 있으며, 어떻게 연락하는지 파악할 수 있어야 한다.

## 2. 목표와 성공 기준

| 목표 | 성공 기준 |
| --- | --- |
| 소유자를 한눈에 소개 | 첫 화면에서 이름, 직무, 한 줄 소개가 보인다. |
| 개발 능력 증명 | 기술 스택과 대표 프로젝트(링크 포함)를 확인할 수 있다. |
| 연락 유도 | 연락처(이메일 등)를 페이지 안에서 바로 찾고 누를 수 있다. |
| 어디서나 열람 | PC와 모바일에서 가로 스크롤 없이 정상 표시된다. |

## 3. 대상 방문자

- 채용 담당자, 개발 팀 리드
- 협업이나 외주를 검토하는 사람
- 소유자의 개발자 네트워크

## 4. 제약 사항

- **데이터베이스와 백엔드를 사용하지 않는다.** 모든 콘텐츠는 저장소 안의 정적 파일(HTML/CSS/JS, 필요하면 로컬 JSON/JS 데이터)로 둔다.
- **한 페이지로 구성한다.** 모든 섹션을 한 화면에서 스크롤로 보여준다.
- 문의 폼이 필요하면 서버 대신 `mailto:` 링크나 외부 폼 서비스를 쓴다.
- 개인 정보는 소유자가 제공한 내용만 쓴다. 없는 항목은 placeholder로 표시한다.
- 페이지 문구는 한국어를 기본으로 한다.

## 5. 섹션 구성

위에서 아래 순서로 배치한다.

1. **히어로**: 이름 `[ ]`, 직무 `[ ]`, 한 줄 소개 `[ ]`, 연락처·포트폴리오로 이동하는 버튼.
2. **소개**: 짧은 자기소개 `[ ]`와 사진 `[ ]`(선택). 출생연도(1990년생)를 표시할지는 소유자가 정한다 `[ ]`.
3. **기술 스택**: 보유 기술을 분류해서 보여준다(언어, 프레임워크, 도구). 목록은 `[ ]`.
4. **포트폴리오**: 프로젝트 카드 목록. 카드마다 이름, 한 줄 설명, 사용 기술, 링크(저장소 또는 데모)를 담는다. 프로젝트 목록은 `[ ]`.
5. **경력·학력** (선택): 타임라인 형태 `[ ]`.
6. **연락처**: 이메일 `[ ]`, GitHub `[ ]`, 기타 링크 `[ ]`.

## 6. 기능 요구사항

| ID | 요구사항 | 우선순위 |
| --- | --- | --- |
| F1 | 상단 고정 내비게이션이 각 섹션으로 부드럽게 스크롤 이동한다. | 필수 |
| F2 | 포트폴리오 데이터는 한 곳(배열 또는 JSON)에 모아 두고, 카드는 이 데이터로 그린다. 프로젝트를 추가할 때 마크업을 고치지 않아도 된다. | 필수 |
| F3 | 이메일과 외부 링크는 클릭으로 동작하고, 외부 링크는 새 탭에서 연다. | 필수 |
| F4 | 모바일, 태블릿, PC에 맞는 반응형 레이아웃. | 필수 |
| F5 | 라이트/다크 테마 전환 | 선택 |
| F6 | 기술 스택이나 프로젝트 필터링 | 선택 |

## 7. 비기능 요구사항

- **무의존 정적 구성**: 빌드 도구나 서버 없이 `index.html`을 브라우저로 열어 확인할 수 있어야 한다. 도구를 도입하게 되면 `CLAUDE.md`의 명령어 항목을 함께 갱신한다.
- **접근성**: 의미 있는 HTML 태그, 이미지 대체 텍스트, 보이는 키보드 포커스, 충분한 색 대비.
- **성능**: 외부 라이브러리를 최소화하고 이미지는 용량을 줄여서 쓴다.
- **SEO/공유**: `title`, `description`, Open Graph 메타 태그를 설정한다.

## 8. 기술 방향

- 기본안: 순수 HTML, CSS, JavaScript. 파일은 `index.html`, `style.css`, `script.js` 또는 단일 파일 중 소유자가 선택 `[ ]`.
- 외부 서비스는 문의 폼이 필요할 때만 선택적으로 사용한다.

## 9. 배포

- 루트 `vercel.json`이 현재 계산기의 `index.html`을 서비스하므로, 이 페이지는 **별도 Vercel 프로젝트**(Root Directory를 `02_1page`로 지정)로 배포하는 방안을 기본으로 한다.
- 루트 `vercel.json`은 소유자 확인 없이 수정하지 않는다.
- 도메인은 `[ ]`.
