# CLAUDE.md

이 파일은 Claude Code(claude.ai/code)가 이 저장소에서 작업할 때 참고하는 안내서입니다. Codex 등 다른 에이전트는 `AGENTS.md`를 통해 이 파일을 참조합니다.

## 프로젝트

1990년생인 소유자를 소개하고 포트폴리오와 개발 능력을 알리는 한 페이지짜리 개인 홈페이지입니다. 디자인은 사이버펑크 테마(네온 시안·핑크·옐로, 그리드 배경, 글리치 제목)입니다. 문서와 페이지 문구는 따로 지시가 없으면 한국어로 작성합니다.

## 제약 사항

- **데이터베이스와 백엔드를 사용하지 않습니다.** 모든 콘텐츠는 저장소 안의 정적 파일(HTML/CSS/JS, 또는 로컬 JSON/JS 데이터)로 둡니다. DB 연결, 인증, 서버 API는 추가하지 않습니다. 문의 폼이 필요하면 서버 대신 `mailto:` 링크나 외부 폼 서비스를 씁니다.
- **한 페이지로 구성합니다.** 소개, 기술 스택, 포트폴리오, 연락처 등 모든 섹션을 한 화면에서 스크롤로 보여줍니다.
- 경력, 프로젝트, 기술, 연락처 같은 개인 정보는 소유자에게서 받은 내용만 씁니다. 지어내지 말고, 받기 전까지는 placeholder임이 분명하게 표시합니다. 단 현재 기술 스택과 프로젝트 3건은 소유자가 직접 요청해서 작성한 예시 내용이며 실제 이력이 아니므로, 실제 정보를 받으면 교체합니다. 이메일 등 연락처는 임의로 만들지 않습니다.

## 상위 저장소와의 관계

이 폴더는 `C:\chaAi`를 루트로 하는 git 저장소의 하위 폴더입니다. 같은 저장소의 계산기 프로젝트는 루트 `vercel.json`(`outputDirectory: "."`)으로 빌드 없이 Vercel에 배포됩니다. 이 루트 설정은 현재 계산기의 `index.html`을 서비스하므로, 이 페이지를 배포하려면 별도 Vercel 프로젝트를 만들거나 루트 디렉터리를 바꿔야 합니다. 루트 `vercel.json`을 수정하기 전에는 소유자에게 먼저 확인합니다.

## 구조

- `index.html`: 섹션 뼈대(히어로, 소개, 기술, 프로젝트, 연락처). 문구의 `[ ]`는 placeholder입니다.
- `script.js`: 상단의 `data` 객체(skills, projects, contacts)가 기술·프로젝트·연락처의 단일 출처이며, 이 데이터로 카드를 그립니다. 항목을 추가할 때는 마크업이 아니라 `data`를 고칩니다.
- `style.css`: 색상은 `:root` 변수(`--cyan`, `--pink`, `--yellow`)로 관리합니다. `prefers-reduced-motion`에서는 애니메이션을 끕니다.

## 명령어

빌드 도구가 없습니다. `index.html`을 브라우저로 열어 확인합니다.
